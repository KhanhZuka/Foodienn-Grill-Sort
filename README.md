# Foodie Grill Sort – 2D Mobile Game

## Introduction
Foodie Grill Sort is a 2D mobile puzzle game where players sort and organize different food items on grills to complete customer orders. 
The game features challenging sorting mechanics, multiple booster systems, and a delivery system that adds variety to the gameplay. 
Developed using Unity and C#.

## Technologies
- Unity 2D
- C#
- DOTween
- Visual Studio

## Features
- Gameplay mechanics and item interactions.
- Booster system: Magnet, Shuffle, Extra Grill.
- Shipper delivery system.
- User Interface (UI).
- Animation effects using DOTween.
- Player data saving using PlayerPrefs.
